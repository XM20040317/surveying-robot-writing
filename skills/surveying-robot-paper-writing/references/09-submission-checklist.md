# 投稿前自查清单

这张清单用于投稿前 48 小时。按顺序过，不要跳步；每项只有“通过”或“明确缺口”两种结果。目标刊物的具体要求，以投稿当期官网作者指南和模板为准，本清单不替代指南。

## 使用说明

- [ ] 先查科学内容和数字图表，再统一语言；早期润色会被后续改图、改结论推翻。
- [ ] 一人主查，另一人只按清单复核；作者本人容易跳过自己熟悉但没写清的地方。
- [ ] 每发现一个缺口，写到单独的问题清单里，标负责人和截止时间，不留在脑子里。
- [ ] 下载目标刊物的最新模板、作者指南和投稿系统检查页，三者对照，不凭旧稿经验。

## 一、科学内容

口径：贡献必须能被实验证据支撑，证据必须能被第三方按文中信息复现或至少复核。

- [ ] 贡献点能用一句话说清：做了什么、比什么好、在什么条件下成立。
- [ ] 每个贡献都对应至少一个实验、表或图，并做过“贡献—实验—结论”映射。
- [ ] 与最接近的 3–5 项工作逐项比较，写清假设、输入、评价口径的差异，不用“首次”代替论证。
- [ ] 基线使用官方代码或公开配置，输入、训练/测试划分和评价脚本与本文一致。
- [ ] 基线有合理的调参预算，并说明预算是否对等；不把没调过的官方默认值当强基线。
- [ ] 真值精度优于论文声称的精度，并有独立检核点、标定和时间同步说明。
- [ ] 明确真值误差如何传播到最终指标；真值不够时，主动收窄精度声明。
- [ ] 训练、验证、测试无场景泄漏；同一地点、同一航次的数据不跨集合。
- [ ] 统计口径写清：随机种子数、均值±标准差或置信区间、配对检验、效应量。
- [ ] “实时”有端到端定义：硬件、批量、分辨率、预处理和通信开销，报均值与高分位延迟。
- [ ] 失败案例有分类、触发条件、发生率和典型图，不只展示成功样本。
- [ ] 局限性覆盖假设、适用场景、数据偏差和负面结果，不用一句“未来工作”带过。
- [ ] 标题、摘要、结论的声明强度一致，没有一处比实验多走一步。
- [ ] 代码、配置、随机种子、数据划分和运行环境有可执行的复现说明。
- [ ] 涉及人类受试者、隐私、敏感区域或野外作业的内容，已按目标刊物和所在机构要求处理。

常见失分：贡献写“提高了精度和鲁棒性”，实验却只有一个场景、一个基线、一次运行。

## 二、结构与逻辑

口径：每一节都要回答一个明确问题；读者只看标题、图表和每段首句，也能复述论文逻辑。

- [ ] 摘要包含具体结果数字，且数字与正文、表格一致。
- [ ] 摘要按“问题—方法—关键结果—结论”组织，不堆背景，不写没有证据的“显著优于”。
- [ ] 摘要不引用文献、不定义非必要缩写；目标刊物允许的写法以其指南为准。
- [ ] 标题具体到任务、平台或关键条件，不用空泛的“Towards …”掩盖贡献不足。
- [ ] 引言是漏斗：应用需求 → 现有方法的缺口 → 本文思路 → 贡献，不写成文献流水账。
- [ ] 贡献列表控制在 3–4 条，每条可在实验节找到对应证据。
- [ ] 相关工作按技术路线或假设分组比较，不逐篇复述摘要。
- [ ] 方法节能让同行复现：符号、流程、关键参数、损失函数和复杂度都有交代。
- [ ] 每个实验前写清它要回答的问题，实验后直接回答，不用“结果如图”结束。
- [ ] 每段有主题句，段内只推进一个论点；长段拆开。
- [ ] 图表按正文首次引用顺序编号，正文解释其含义，而不是重复读数。
- [ ] 讨论节解释“为什么”，包括与预期不符的结果，不把结果节再抄一遍。
- [ ] 结论不引入新数据、新方法、新引用，只回收已经证明的结论。
- [ ] 节与节之间有过渡，方法、实验、讨论的篇幅与贡献权重匹配。
- [ ] 全文没有“待补实验”“待定参数”这类提交前未清理的标记。

常见失分：引言最后一段列了 5 条贡献，实验只覆盖 3 条，另外 2 条靠讨论中的推测支撑。

## 三、数字与图表

口径：每个数字都能追溯到数据或脚本；每张图在黑白打印、网页缩略图和 PDF 放大三种场景下都能读。

- [ ] 统一使用 SI 单位，非标准单位首次出现时给出换算。
- [ ] 有效数字与测量精度匹配，不把 3.14159 m 写成厘米级精度。
- [ ] 误差棒写明含义（标准差、标准误、置信区间）和样本数 n。
- [ ] 均值、误差、样本数三者同时出现；只给均值不给离散度的结果不进入结论。
- [ ] 表格行列合计、百分比、差值能对上，四舍五入造成的偏差有说明。
- [ ] 色标范围、单位和正负方向一致；对比方法使用同一色标范围。
- [ ] 配色在色盲和灰度下可区分，不靠红绿单独编码类别。
- [ ] 地图有比例尺、指北针、坐标框架和必要的审图号/数据来源说明。
- [ ] 坐标轴有名称和单位，刻度可读，不截断会误导的纵轴。
- [ ] 线图用矢量格式；位图按目标刊物分辨率要求导出，不反复压缩。
- [ ] 字体已嵌入，缩放后最小字号仍可读；图内文字与正文术语一致。
- [ ] 图注自明：是什么、在什么设置下得到、n 是多少、误差棒代表什么。
- [ ] 表注定义缩写、符号和显著性标记，读者不翻正文也能读懂。
- [ ] 同一数据不在正文、表、图中重复三遍；保留信息量最大的呈现形式。
- [ ] 所有数字由同一版脚本生成；改过一次数据后，全文重新导出并核对。

常见失分：图 5 的色标上限是 0.2 m，图 6 是 2 m，正文却直接比较两图的颜色深浅。

## 四、术语与语言

口径：术语服务于精确性，不服务于“看起来高级”；同一概念全文只用一个词。

- [ ] 缩写首次出现时给全称，摘要和正文分别处理；目标刊物有特殊要求时从其规定。
- [ ] 同一概念不混用多个译名或英文词，例如 pose/position、accuracy/precision、map/mapping。
- [ ] 建立中英术语对照表，方法名、模块名、指标名在标题、图、表中一致。
- [ ] 不把 accuracy、precision、uncertainty、resolution 当同义词使用。
- [ ] 时态统一：方法用过去时或现在时均可，但全文一致；结果用过去时，普遍事实用现在时。
- [ ] 主动语态和被动语态按信息重点选择，不整篇堆“was performed”。
- [ ] 删掉 AI 味填充句，例如“值得注意的是”“综上所述”“It is worth noting that”“delve into”。
- [ ] “significant”“robust”“real-time”“first”只在有统计或实验定义时使用。
- [ ] 符号表完整，同一符号不承担两个含义，上下标格式统一。
- [ ] 长句拆短，一句只表达一个逻辑关系；方法节尤其避免多重从句。
- [ ] 中文标点、英文标点和全半角统一；数字与单位之间空格按目标模板处理。
- [ ] 引用融入句子语法，不出现“文献 [3] 做了……”与“文献 [4] 也做了……”的连续排比。
- [ ] 最后一遍由同行读出声检查；机器翻译痕迹和本地化表达要人工改掉。

常见失分：摘要说“高精度”，方法说“厘米级”，实验表里的 RMSE 是 0.35 m，三处各说各话。

## 五、引用与学术规范

口径：引用过的每一篇都真正读过；声明过的每一项材料都真实存在；署名和利益关系经所有作者确认。

- [ ] 每条引用都读过原文，至少读过摘要、方法和结论，不用二手转引支撑关键论点。
- [ ] 关键论断引用原始论文，不引用综述代替原始实验。
- [ ] 核对作者、年份、卷期、页码和 DOI；撤稿或更正的文献已处理。
- [ ] 自引比例合理且与主题相关，不为了抬高引用而堆自己的旧作。
- [ ] 近五年工作与经典工作都有覆盖，不漏掉同领域直接竞争的方法。
- [ ] 使用或改写他人图表已取得许可，并在图注中注明来源和许可类型。
- [ ] 数据可用性声明与实际一致：能公开给链接，不能公开说明限制和申请方式。
- [ ] 代码可用性声明与实际一致：仓库可访问，含运行说明、配置和依赖。
- [ ] 利益冲突声明覆盖资金、企业合作、专利和顾问关系。
- [ ] 基金资助、项目编号和致谢信息准确，与投稿系统填写一致。
- [ ] 按目标刊物要求披露 AI 工具的使用范围和用途；不用 AI 生成未核实的引用或结果。
- [ ] 作者顺序、通讯作者和贡献分工经全体作者确认，并按刊物要求提供贡献声明。
- [ ] 论文未一稿多投，未整体复用已发表内容；扩展会议论文时说明新增部分。
- [ ] 已做查重和自抄袭检查，方法与结果的文字表述没有与旧文逐句重合。
- [ ] 涉及人类受试者、个人信息或受限地理数据时，伦理审批、脱敏和授权文件齐全。

常见失分：参考文献里有一篇“看起来相关”但没读过的论文，审稿人恰好是作者。

## 六、投稿材料

口径：投稿系统里填的、信里写的、正文里声明的是同一套事实；任何一处不一致都可能退回。

- [ ] Cover letter 说明论文题目、投稿类型、核心缺口、主要贡献和与目标刊物的契合点。
- [ ] Cover letter 不重复摘要，不写“our work is the first”，不承诺论文中没有的内容。
- [ ] Highlights 按目标刊物格式提交，每条是结果而不是主题，能与摘要数字对应。
- [ ] Graphical abstract 在缩略图尺寸下仍能看懂，不引入正文没有的新数据。
- [ ] 推荐审稿人来自相关领域，机构分布合理，排除有合作、师生或利益关系的人。
- [ ] 如允许，填写需要回避的审稿人并给简短、可核实的理由。
- [ ] 补充材料只放推导、扩展实验、视频和大表，核心结论仍能在主文独立成立。
- [ ] 作者贡献、通讯作者、单位、邮箱和 ORCID 在系统与稿件中完全一致。
- [ ] 关键词覆盖任务、平台、方法和应用，不用过于宽泛的词凑数。
- [ ] 双盲审稿时，正文、图、补充材料、代码链接和文件属性中都没有作者身份信息。
- [ ] 稿件文件格式、命名、图表是否单独上传，均按投稿系统要求执行。
- [ ] 数据、代码、利益冲突、基金和 AI 使用声明同时出现在正文与系统对应字段。
- [ ] 若刊物要求单独上传图件，确认文件名、格式、分辨率和编号与正文一致。
- [ ] 提交前生成最终 PDF，逐页检查公式、图、表、页码和参考文献是否断裂。
- [ ] 投稿系统里的标题、摘要、作者顺序与 PDF 一致，粘贴后没有截断或乱码。

常见失分：正文写“代码将公开”，投稿系统却选“代码不公开”；或者匿名稿的 GitHub 链接带着作者姓名。

## 七、按目标刊物的最后一公里

先下载当年模板，再用投稿系统预览做最终判断。下表只列检查维度，具体数值和格式一律以作者指南为准。

| 检查项 | ISPRS J / TGRS 类 | RA-L/ICRA 类 | 中文核心类 |
|---|---|---|---|
| 页数与版面 | 按刊物版面规则和超页政策，以指南为准 | 有硬性页数限制，参考文献和附录是否计入以模板为准 | 版面和图数常受限，提前按模板估算 |
| 摘要与关键词 | 结构式或非结构式、字数以指南为准 | 字数空间紧，优先保留问题、方法和关键结果 | 中英文摘要都要打磨，中文避免英文长句直译 |
| 图数与尺寸 | 上限不固定，按版面控制，能放补充材料的放补充材料 | 主文图要少而关键，扩展结果分流到补充材料 | 图数受版面影响，先确认编辑部要求 |
| 参考文献风格 | 严格使用刊物模板，DOI 和页码完整 | 期刊与会议格式不同，不要混用旧 bib | 按 GB/T 7714 或期刊自定格式，以最新模板为准 |
| 补充材料 | 是否允许、允许的格式和大小以指南为准 | 视频、代码和扩展实验常用，但不承载核心结论 | 以编辑部要求为准，提前确认能否上传 |
| 数据与代码 | 按刊物数据政策写声明，链接可访问 | 开源是加分项，但不能替代方法可复现性 | 基金、数据来源和版权声明按期刊要求 |
| 匿名要求 | 按刊物的审稿模式处理 | 双盲会议必须彻底匿名，包括元数据 | 按编辑部要求处理作者信息 |
| 模板与文件 | 使用官网 LaTeX/Word 模板，不套用旧版 | 使用当年会议模板和页数设置 | 使用期刊最新排版模板和图表规范 |
| 语言与术语 | 英文写作，术语遵循领域惯例 | 英文写作，页数限制下优先清晰 | 中文规范，英文摘要单独请人复核 |
| 系统字段 | 作者、基金、利益冲突与正文一致 | 摘要截断、主题分类和版权选项逐项核对 | 中图分类号、基金信息和作者简介齐全 |

最后三步：

1. 用“作者指南—模板—系统预览”三处交叉检查，任何一处不一致都以官网当期说明为准。
2. 让一位没参与写作的同行只看题目、摘要和图，复述论文贡献；复述不出，说明还没收紧。
3. 提交前把最终版 PDF 和源文件各存档一份，记录提交时间、稿件编号和系统回执。

## 一页纸速查

- [ ] 贡献不能用一句话说清，或一句话里出现两个“首次”。
- [ ] 没有公平基线：输入不同、划分不同、调参预算不同。
- [ ] 真值精度不支持声称精度，且没有误差预算。
- [ ] 只有一个场景、一个平台或一次运行，却下通用结论。
- [ ] 没有失败案例和局限性，审稿人只能自己找弱点。
- [ ] 摘要、正文、表格、图注的数字互相矛盾。
- [ ] 图在灰度或缩略图下不可读，地图缺比例尺和坐标框架。
- [ ] 统计只有均值，没有离散度、样本数和检验。
- [ ] 参考文献没读过、信息不全，或引用与论断不匹配。
- [ ] 数据/代码声明与实际不符，匿名稿泄露身份。
- [ ] 超过页数或格式硬限制，投稿系统预览报错。
- [ ] 标题、摘要、结论的声明比实验多走一步。
