# 指标、精度与统计口径

**同一个 RMSE，可以因为对齐方式、是否剔除粗差、分母取 n 还是 n−1，差出一倍。** 所以审稿人第一件事不是看数值，是看你怎么算的。这一节的目标：让你报的每个数都经得起复算。

---

## 三个词先分清

| 词 | 英文 | 含义 | 对应统计量 |
|---|---|---|---|
| **准确度** | accuracy | 与真值的接近程度（综合） | RMSE、最大误差 |
| **正确度** | trueness | 系统偏差的大小 | 平均误差（bias） |
| **精密度** | precision | 重复观测的分散程度 | 标准差、极差 |

三者独立。**可以很精密但很不准**（每次都偏 +5 cm，标准差 2 mm）——这是系统性误差，靠重复实验永远修不好。

---

## 中误差与 RMSE

在测绘语境里，两者多数时候是一回事，但写法有讲究：

```text
中误差（已知真值）：  m = ± sqrt( Σ(Δᵢ²) / n )        Δᵢ = 观测值 − 真值

中误差（白塞尔公式）： m = ± sqrt( Σ(vᵢ²) / (n−1) )    vᵢ = 观测值 − 最或然值

限差：                通常取 2m 或 3m（以相应规范为准）
```

**报中误差时必须说明**：用的是真值还是最或然值、分母是 n 还是 n−1、是否剔除粗差（剔除规则是什么）。

RMSE 与中误差数值相同、含义相同，**英文论文统一用 RMSE**，中文论文统一用"中误差"，不要一篇里混用。

### 点位中误差

```text
平面点位中误差： m_P = ± sqrt( (Σ(Δxᵢ²) + Σ(Δyᵢ²)) / n )
高程中误差：     m_H = ± sqrt( Σ(Δzᵢ²) / n )
三维点位中误差： m_3D = ± sqrt( (Σ(Δxᵢ²) + Σ(Δyᵢ²) + Σ(Δzᵢ²)) / n )
```

**平面和高程必须分开报。** 只报三维合成值，会掩盖高程方向的系统性偏差——这是本领域最常见的报数错误之一。

## 指标总表

### 通用误差指标

| 指标 | 定义 | 单位 | 什么时候用 | 陷阱 |
|---|---|---|---|---|
| ME（平均误差） | `mean(Δ)` | m | 看系统偏差 | 正负抵消，不能单独用 |
| MAE | `mean(|Δ|)` | m | 抗粗差 | 不如 RMSE 敏感于大误差 |
| RMSE | `sqrt(mean(Δ²))` | m | 主指标 | 对粗差极敏感，须同时报最大误差 |
| STD | `std(Δ)` | m | 看离散度 | 与 ME 一起才能还原 RMSE |
| P95 | 95% 分位 | m | 稳健上界 | 样本少时不可靠 |
| Max | 最大误差 | m | 最坏情况 | 单个外点就能主导 |

> **RMSE 与 MAE、P95、Max 至少各报一个。** 只报 RMSE，审稿人无法判断是不是被几个外点撑起来的。

### 轨迹指标（SLAM / 里程计）

| 指标 | 定义 | 单位 | 口径必须写清 |
|---|---|---|---|
| **ATE** | 对齐后逐帧位置误差的 RMSE | m | 对齐方式（SE(3)/Sim(3)/首帧）、是否估尺度 |
| **RPE** | 固定间隔 Δ 的相对位姿误差 | % / (°/m) | Δ 取多少、按距离还是按帧 |
| **drift** | 末端误差 / 轨迹长度 | % 或 %/100 m | 是否含回环、是否取平均 |
| **t_rel / r_rel** | KITTI 口径：分段长度 100–800 m 上的平均相对平移/旋转误差 | % / (°/m) | 必须按 KITTI 的分段协议 |
| 初始化时间 | 到收敛所需时长 | s | 收敛判据是什么 |
| 实时性 | 单帧耗时均值 / P95 / 最大 | ms | 硬件、线程数、是否含预处理 |

**ATE 的对齐陷阱**：用 Sim(3) 对齐会把尺度误差吸收掉，看起来更准；用 SE(3) 更严格。**必须写明用哪种，并在所有方法上统一。**

### 点云指标

| 指标 | 定义 | 单位 | 用于 |
|---|---|---|---|
| C2C 距离 | 到参考点云最近邻距离的均值/中位数 | m | 整体一致性 |
| M3C2 | 沿法向的距离及其置信区间 | m | 变形/变化检测，抗噪声 |
| 点到面距离 | 到拟合平面的距离 | m | 平面/结构面精度 |
| 完整性 | 覆盖到的参考点比例 | % | 有没有漏 |
| 点密度 | 单位面积/体积点数 | pts/m² | 成果可用性 |
| 粗差率 | 超过阈值的点占比 | % | 质量分级 |

**只报精度不报完整性，等于只说对了一半。** 一个只重建了 60% 表面的模型，精度再高也不可用。

### 配准指标

| 指标 | 定义 | 单位 |
|---|---|---|
| RRE | 相对旋转误差 | ° |
| RTE | 相对平移误差 | m |
| Recall@(5 cm, 5°) | 满足该阈值的配准对比例 | % |
| 内点率 | 判为内点的对应点比例 | % |

阈值必须写出来，且与对比方法一致（3DMatch 系惯用 5 cm / 5°）。

### 摄影测量与制图指标

| 指标 | 定义 | 说明 |
|---|---|---|
| GSD | 地面采样距离 | 决定理论精度上限 |
| RMSE_XY / RMSE_Z | 检查点平面/高程中误差 | 检查点必须独立于像控点 |
| CE90 / LE90 | 90% 置信的圆/线误差 | ASPRS 体系常用 |
| 相对精度 | 模型内部一致性 | 与绝对精度分开报 |

**检查点数量与分布**要写：不少于 20 个、均匀覆盖、含边角。分布图比数字更有说服力。

## 有效数字与单位

| 规则 | 正确 | 错误 |
|---|---|---|
| 精度不超过真值精度 | 真值 cm 级 → 报 `0.03 m` | `0.0314 m` |
| 中误差保留 2 位有效数字 | `0.042 m` | `0.04213 m` |
| 单位与数值间空格（英文） | `12.5 cm` | `12.5cm` |
| 百分号前不空格 | `35%` | `35 %` |
| 范围写法一致 | `0.8–1.2 m` | `0.8-1.2m` |
| ± 用法 | `2.4 ± 0.3 cm` | `2.4cm±0.3` |
| 中文单位用中文符号 | `12.5 厘米` 或 `12.5 cm`（全文统一） | 中英混排 `12.5cm厘米` |

**一条铁律：论文里出现的每个数字，都必须能在表格或图里找到对应的来源。**

## 统计口径

| 场景 | 报法 | 备注 |
|---|---|---|
| 确定性算法、单次 | 单值 + 说明"确定性" | 不要假装有误差棒 |
| 随机性算法 | `mean ± std`（n=5 或 10） | 写清 n |
| 方法对比 | 配对检验 + p 值 + 效应量 | 样本 <5 不做检验 |
| 实时性 | 均值 / P95 / 最大值 | 写硬件与线程 |
| 大样本误差分布 | 直方图或 CDF | 比单个 RMSE 信息量大 |

**不要用 `±` 表示置信区间却不说置信水平。** 要写 `95% CI` 或 `k=2`。

## 十二个常见错误

| # | 错误 | 后果 | 改法 |
|---|---|---|---|
| 1 | 用 RMSE 掩盖粗差 | 数值好看但不可信 | 同时报 Max / P95 / 粗差率 |
| 2 | 平面高程混报 | 掩盖高程系统偏差 | 分开报 |
| 3 | ATE 对齐方式不写 | 无法复算 | 写明 SE(3)/Sim(3) |
| 4 | 只报均值不报标准差 | 看不出稳定性 | `mean ± std, n=?` |
| 5 | RTK 当真值报毫米级 | 直接被拒 | 按真值精度降级表述 |
| 6 | 检查点当像控点用 | 精度虚高 | 严格分开 |
| 7 | 点云只报精度不报完整性 | 结论片面 | 补完整性/密度 |
| 8 | 单位混用 | 审稿人算不对 | 全文统一 |
| 9 | 百分比基数不明 | "提升 30%" 相对谁 | 写 `relative to <baseline>` |
| 10 | 有效数字过多 | 显得不专业 | 按真值定 |
| 11 | 只报最好场景 | 选择性报告 | 全场景表格 |
| 12 | 该做检验不做 | 差异可能是噪声 | 配对检验 |

## 报告模板

英文：

```text
Accuracy is evaluated against <reference>, whose uncertainty is <u>
(k = 2). The proposed method achieves an RMSE of <x> m (mean <m> m,
maximum <M> m) over <n> sequences, compared with <y> m for <baseline>.
Planar and vertical errors are reported separately in Table <k>.
All methods are aligned with SE(3) before evaluation.
```

中文：

```text
以〈参考基准〉为真值，其不确定度约为〈u〉（k=2）。
本文方法的点位中误差为〈x〉m（平均误差〈m〉m，最大误差〈M〉m），
共〈n〉段数据；对比方法〈基线〉为〈y〉m。
平面与高程精度分列于表〈k〉，所有方法统一采用 SE(3) 对齐。
```

## 一句话记住

> **报精度不是报一个数，是报一套可复算的口径。** 定义、对齐、样本量、统计方式、真值来源，五样齐全才算报过。
