# 选刊与反向工程

选刊不是选影响因子，是选**读者**和**评价标准**。同一份工作，投 ISPRS J 要求你证明"对测绘有意义"，投 RA-L 要求你证明"方法在机器人上真的能跑"。标准换了，实验和写法都得换。

---

## 第一步：先判断你写的是哪一种论文

| 类型 | 一句话特征 | 主战场 |
|---|---|---|
| **方法论文** | 提出一种新的估计/配准/重建机制，用实验证明更准更稳 | T-RO、RA-L、ICRA/IROS、ISPRS J、TGRS |
| **系统论文** | 一套能跑的平台/流程，重点是集成、标定、鲁棒性与现场表现 | JFR、Field Robotics、TIM、Automation in Construction、Remote Sensing |
| **评测/数据集论文** | 提出基准、数据集、评价协议，或系统性地"打假" | ISPRS J、TGRS、IJRR 类、会议数据集 track |
| **应用论文** | 把成熟方法用到某类工程问题，重点是适配与效果 | 中文核心、JAG、Measurement、PE&RS |

**类型决定篇幅、实验量和审稿人。** 先定类型，再定刊。把方法论文投系统刊、把系统论文投理论刊，都会死在"贡献不匹配"上。

## 摄影测量与遥感类

| 刊物 | 定位 | 吃这一套 | 死在这一条 | 篇幅/节奏 |
|---|---|---|---|---|
| **ISPRS J. Photogrammetry and Remote Sensing** | 本领域旗舰，方法要落到"测量"上 | 严格的精度评定 + 明确的测绘意义 + 可复现 | 只有深度学习模块堆叠，没有测绘问题的回答 | 长文，图多，要求完整实验 |
| **ISPRS Open J. Photogrammetry and RS** | 同门开放获取，接受更窄的专题 | 单一问题做透 | 故事太散 | 中等 |
| **IEEE TGRS** | 遥感信号/学习，体量大 | 新数据集 + 充分对比 + 泛化实验 | 只在自有数据上验证，缺跨域 | 长文 |
| **IEEE JSTARS** | 应用导向遥感 | 真实场景 + 工程价值 | 方法新意不足又不讲应用 | 中等 |
| **Remote Sensing (MDPI)** | 快、宽、OA | 系统完整、实验扎实 | 创新薄弱、写作松 | 较快，但需付 APC |
| **The Photogrammetric Record** | 摄影测量传统阵地 | 几何严密、误差传播清楚 | 只讲工程不讲几何 | 中等 |
| **PE&RS** | ASPRS 会刊，偏规范与应用 | 与行业标准/精度标准对接 | 纯算法、无测绘语境 | 中等 |
| **Geo-spatial Information Science** | 中国主办，国际发行 | 空间信息方法 + 中国场景 | 英文表达不过关 | 中等 |
| **JAG（Int. J. Applied Earth Obs. Geoinf.）** | 应用地观测 | 应用闭环 | 方法平 | 中等 |

> 这几本刊的共同口味：**精度要经得起算**。真值、检查点数量、分布、统计口径，一个含糊就会被要求补实验。

## 机器人与系统类

| 刊物/会议 | 定位 | 吃这一套 | 死在这一条 |
|---|---|---|---|
| **IEEE T-RO** | 机器人理论最高门槛之一 | 有理论保证、有系统性实验 | 工程拼装、缺分析 |
| **Science Robotics** | 极少数 | 范式级贡献 | 增量改进 |
| **IEEE RA-L** | 快、新、6 页正文（参考文献另计，以当年规定为准） | 一个清楚的新点 + 干净实验 | 实验不完整、写作超页 |
| **ICRA / IROS** | 会议，6 页（以当年 CFP 为准） | 方法新意 + 可行 | 只有仿真、对比不全 |
| **RSS** | 单轨，重理论 | 问题定义漂亮 | 工程报告式写法 |
| **CoRL** | 学习与具身 | 强 baseline、消融彻底 | 只报最好结果 |
| **JFR（Journal of Field Robotics）** | 野外系统 | 真实部署、长时运行、失败分析 | 实验室里跑通就投 |
| **Field Robotics** | 同类新刊 | 平台与现场数据 | 同上 |
| **IEEE TIM** | 仪器与测量 | 测量原理 + 不确定度分析 | 把系统论文写成产品说明 |
| **IEEE Sensors Journal** | 传感器系统 | 标定 + 信号处理 | 缺 ground truth |
| **Automation in Construction** | 建造/监测自动化 | 工地场景闭环 | 场景不真实 |

> RA-L 与 ICRA/IROS 是**同一份工作的两种投法**：先投 RA-L，中了去 ICRA/IROS 讲；或先投会议再扩期刊。扩刊时必须有新增内容（新实验、新分析），否则算重复发表。

## 中文核心

| 刊物 | 适合什么 | 注意 |
|---|---|---|
| **测绘学报** | 测绘学科的方法与理论 | 要求明确的测绘问题 + 精度评定，英文摘要质量被严查 |
| **武汉大学学报·信息科学版** | 摄影测量、GIS、导航 | 偏理论与方法 |
| **测绘科学技术学报** | 工程与军事测绘 | 应用与工程性强 |
| **地球信息科学学报** | 地理信息、时空分析 | 偏 GIS 与数据 |
| **导航定位学报** | GNSS/组合导航 | 定位与完好性 |
| **中国惯性技术学报** | IMU/组合导航 | 惯性器件与算法 |
| **机器人（ROBOT）** | 机器人系统与方法 | 要有实物实验 |
| **仪器仪表学报** | 测量仪器 | 硬件 + 计量 |
| **自动化学报** | 控制与估计 | 理论门槛高 |

中文刊不等于"好中"。**图和表的规范、量纲、有效数字、参考文献格式，比英文刊查得更细。**

## 选刊决策树

```
你的核心证据是什么？
├─ 精度/鲁棒性显著优于现有方法
│   ├─ 且能说清"对测绘意味着什么" → ISPRS J / PE&RS
│   ├─ 且是学习方法为主       → TGRS / JSTARS
│   └─ 且是机器人系统         → RA-L / ICRA / T-RO
├─ 一套系统在真实场景长期跑通
│   ├─ 野外/工程现场 → JFR / Field Robotics / Automation in Construction
│   └─ 仪器与测量     → TIM / Measurement
├─ 数据集、基准、评价协议
│   └─ ISPRS J / TGRS / 会议数据集 track
└─ 工程应用与规范对接
    └─ 中文核心 / PE&RS / JAG
```

三条硬约束：

1. **Scope 第一。** 编辑初筛只看"这篇是不是我们的范围"。去目标刊近两年目录里找 3 篇和你最像的，找不到就别投。
2. **别用影响因子选刊。** 用"审稿人是谁、他们关心什么"选。测绘刊的审稿人会算你的中误差，机器人刊的审稿人会问你跑不跑得动。
3. **时间成本要算进去。** 会议有硬 deadline，期刊没有。赶毕业就会议+期刊双轨，别赌单一期刊的周期。

## 反向工程：四步拿到目标刊的隐性规范

这是全库最值钱的方法。**规范会变，方法不过时。**

**准备**：4 篇以上目标刊、近 3–5 年、对象与手段和你接近的论文（其中至少 2 篇中国作者）。

**第 1 步 · 数结构**
逐节数段数、句数。填这张表（每篇一行）：

| 论文 | 引言段数 | 相关工作段数 | 方法段数 | 实验小节数 | 结果图数 | 结果表数 | 讨论段数 | 参考文献数 |
|---|---|---|---|---|---|---|---|---|

**第 2 步 · 标功能**
给引言每一句标功能，不要标内容。功能标签只用这几个：

`领域重要性` `已有方法` `具体缺口` `本文做法` `贡献1/2/3` `结构预告`

标完 4 篇，你会发现目标刊的引言几乎是同一个骨架，只是填的东西不同。

**第 3 步 · 抽句式**
把高频动词、连接词、精度表述抄下来。重点抄这几类：

- 缺口怎么说（`however, existing methods…` / `remains challenging when…`）
- 贡献怎么起头（`We propose…` / `This paper presents…` / `The main contributions are:`）
- 精度怎么报（`achieves an RMSE of X m, a Y% reduction over…`）
- 局限怎么认（`A limitation of our approach is…`）

**第 4 步 · 建自己的画像卡**

```markdown
## 目标刊画像卡：<刊名>
- 近三年同主题论文：<3-5 篇标题>
- 引言骨架：重要性(1段) → 现有方法(2段) → 缺口(1段) → 本文(1段) → 贡献(1段)
- 实验标配：<场景数> 个场景 / <基线数> 个基线 / <消融组数> 组消融
- 精度表述惯例：<例：报 RMSE 与最大值，不报均值>
- 图表惯例：<例：必有系统框图 + 轨迹图 + 误差 CDF>
- 平均参考文献数：<n>
- 我最像的那篇：<标题>，差距在：<…>
```

## 选刊的五个常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 按分区/影响因子选 | 投出去 scope 不符，编辑秒拒 | 按"读者是谁"选 |
| 一稿多投 | 学术不端，可能被拉黑 | 严格串行，或明确的双轨（会议→扩刊） |
| 忽略 APC 与版面 | 中了付不起 | 投稿前确认经费 |
| 拿会议论文直接扩刊 | 被判重复发表 | 新增 ≥30% 新内容并声明 |
| 只看期刊名不看审稿人 | 回复信答不到点上 | 读该刊近作的"回复"痕迹（有的刊公开） |

## 一条实用建议

**先写"目标刊差距表"，再动笔。**

```markdown
| 目标刊标配 | 我现在有 | 缺口 | 补的代价 |
|---|---|---|---|
| 3 个场景 | 1 个 | 缺隧道/动态场景 | 2 周采集 |
| 4 个基线 | 2 个 | 缺 FAST-LIO2 | 3 天复现 |
| 真值 ≤1cm | RTK 5cm | 真值比精度差 | 需全站仪 |
```

这张表填完，你会发现真正决定投哪本的，不是你的算法，是你的**真值**。
