# 图与表

审稿人读论文的顺序是：**标题 → 摘要 → 图 → 表 → 正文**。图和表不是"配图"，是论文的主证据。

---

## 一条原则

> **一张图只讲一个结论。** 讲不完就拆成两张。

判断方法：给这张图写一句图注。如果这句话里有两个"并且"，拆图。

---

## 图型清单

| 图型 | 讲什么 | 必须有 | 常见错误 |
|---|---|---|---|
| 系统框图 | 数据怎么流、模块怎么连 | 输入/输出、频率、坐标系 | 模块太多、箭头无标签 |
| 坐标系/几何示意 | 变量定义、几何关系 | 所有符号与图一致 | 图中符号与正文不符 |
| 场景照片 | 实验条件 | 比例参照、设备可见 | 只放好看的那张 |
| 轨迹图 | 全局形状与漂移 | 等比例坐标轴、起终点、真值 | 坐标轴不等比 |
| 点云对比图 | 结构完整性与噪声 | 同一视角、同一色标、比例尺 | 各方法视角不同 |
| 误差 CDF | 误差分布 | 横轴单位、图例、样本数 | 只画均值 |
| 箱线图 | 多场景离散度 | 样本数、异常值说明 | 箱线图当柱状图用 |
| 时序曲线 | 随时间的行为 | 单位、关键时刻标注 | 线条过多无法分辨 |
| 热力图 | 空间分布 | 色标单位、坐标系 | 色标不可读 |
| 消融柱状图 | 模块贡献 | 误差棒、基线 | 不标显著性 |

## 通用制图规范

| 项 | 要求 |
|---|---|
| 最终字号 | ≥7 pt（正文缩放后仍可读） |
| 线宽 | 1.0–1.5 pt |
| 单栏宽 | 约 8.5 cm；双栏约 17–18 cm |
| 位图分辨率 | ≥600 dpi；能矢量的必须矢量（PDF/EPS/SVG） |
| 配色 | 色盲友好（Okabe–Ito、viridis 类），**不要用 matplotlib 默认色** |
| 字体 | 英文 Times/Arial；中文宋体/黑体，全文统一 |
| 坐标轴 | 必须有量和单位：`Error (cm)` 而不是 `Error` |
| 图例 | 放图内空白处，不遮挡数据 |
| 子图 | 用 `(a) (b) (c)` 标注，图注里解释每个子图 |

**导出检查**：把图缩到论文实际尺寸再看一遍。字号小于 7 pt 的，重画。

## 点云图专章

点云图最容易糊弄，也最容易被识破。

| 要求 | 做法 |
|---|---|
| 同一视角 | 所有方法用同一相机位姿渲染 |
| 同一色标 | 按高度/误差着色时，色标范围必须一致 |
| 色标带单位 | 右侧色标写 `Elevation (m)` 或 `Error (cm)` |
| 比例尺 | 图内加 `10 m` 标尺 |
| 点大小一致 | 不同方法用不同点大小 = 作弊 |
| 局部放大 | 用方框标出区域，旁边放放大图 |
| 差异图 | 除了"好看"，要有一张误差着色图 |

**最有力的一张图**：同一区域、同一视角、并排三张——真值 / 基线 / 本文，误差用同一色标。审稿人一眼就能看出差别。

---

## 轨迹图专章

| 要求 | 说明 |
|---|---|
| **等比例坐标轴** | `axis equal`。不等比会把 3 m 的漂移画成 30 m，也会把 30 m 画成 3 m |
| 真值用虚线 | 与估计值区分 |
| 起终点标记 | 圆点/三角，图注说明 |
| 局部放大 | 漂移往往只在某段明显，必须放大 |
| 多方法叠加 | 不超过 4 条，否则拆图 |
| 误差时间序列 | 配一张位置误差随距离变化的曲线 |

---

## 误差图的选型

| 样本量 | 推荐 | 理由 |
|---|---|---|
| <10 | 散点图 + 均值线 | 箱线图在小样本下会骗人 |
| 10–100 | 箱线图 | 能看分布与异常值 |
| >100 | CDF 或小提琴图 | 箱线图丢失分布形状 |
| 方法对比 | CDF（同一张图多条曲线） | 一眼看出谁在尾部更好 |

**CDF 的横轴要用对数刻度**（误差跨数量级时），否则曲线全挤在左边。

## 表格

### 三线表

```
─────────────────────────────────────────
 方法            场景 A      场景 B      场景 C
─────────────────────────────────────────
 Baseline-1     1.23        2.45        3.01
 Baseline-2     0.98        1.87        2.66
 Ours           0.41        0.72        0.95
─────────────────────────────────────────
```

规则：

- 只有顶线、表头线、底线；**不要竖线，不要斑马纹**
- 最优值加粗；次优可加下划线（全文统一）
- 单位写在表头：`RMSE (cm)`，不写在每个格子里
- 样本量写在表注：`n = 10 sequences`
- 显著性用上标字母或 `*`，表注解释
- 小数位数全文统一

### 表格的三个层次

1. **总表**：方法 × 场景 × 指标，一页放下，最优加粗 —— 审稿人只看这张
2. **分表**：每个场景的细节（每段轨迹的结果）
3. **消融表**：模块 × 指标

**总表必须能独立读懂**：不看正文也知道每列是什么、单位是什么、越大越好还是越小越好。

## 图注与表注

图注三件事：**这是什么 + 关键设置 + 一句结论**。

```text
Fig. 5. Trajectories in the tunnel sequence (Seq. 3, 1.2 km).
All methods are aligned to the reference by SE(3). The proposed method
follows the reference after 600 m, whereas baselines drift laterally.
```

中文：

```text
图 5  隧道场景（序列 3，1.2 km）轨迹对比。
各方法均以 SE(3) 对齐至参考轨迹。本文方法在 600 m 后仍贴合参考轨迹，
对比方法出现横向漂移。
```

**禁忌**：图注里重复正文整段；图注只有"如图所示"；图注与正文结论矛盾。

## 十五个常见问题

| # | 问题 | 修法 |
|---|---|---|
| 1 | 直接截图（PPT、Excel、屏幕） | 重新用矢量工具画 |
| 2 | matplotlib 默认配色 | 换色盲友好配色 |
| 3 | 坐标轴无单位 | 补 `(m)` `(cm)` `(s)` |
| 4 | 轨迹图坐标轴不等比 | `axis equal` |
| 5 | 一张图塞三个结论 | 拆图 |
| 6 | 3D 点云图看不出结构 | 换视角 + 加局部放大 |
| 7 | 色标无单位、范围不一致 | 统一色标并标单位 |
| 8 | 位图 72 dpi | 600 dpi 或矢量 |
| 9 | 字号 5 pt | ≥7 pt |
| 10 | 表格用截图 | 用真表格 |
| 11 | 最优值没加粗 | 加粗 + 表注说明 |
| 12 | 没有误差棒 | 补 std 或 CI |
| 13 | 图序与正文引用不符 | 通读校对 |
| 14 | 中英文标点混用 | 中文图注用中文标点 |
| 15 | 图例遮挡数据 | 移到空白处或图外 |

## 图表自检

- [ ] 每张图能用一句话说清结论吗？
- [ ] 缩到实际尺寸后还看得清吗？
- [ ] 所有坐标轴都有量和单位吗？
- [ ] 轨迹图是等比例吗？
- [ ] 点云图的视角、色标、点大小一致吗？
- [ ] 总表能独立读懂吗？
- [ ] 最优值标出来了吗？
- [ ] 图注写了关键设置和结论吗？
- [ ] 每张图都在正文里被引用并解释了吗？
- [ ] 有没有只"展示"不"论证"的图？删掉或改。
